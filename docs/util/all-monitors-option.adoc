--all::
Alias for `--monitor all`.
Please use this option *with caution*.
Use it when you really need to get workspaces/windows from *all monitors*.
+
For a multi-monitor setup, `--monitor focused` is almost always the preferred option.
If you're automating something, then you don't want to mess with workspaces/windows on a different monitor.
+
With great power comes great responsibility.
