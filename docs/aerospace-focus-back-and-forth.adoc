:manpurpose: Switch between the current and previously focused elements back and forth

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospace focus-back-and-forth [-h|--help]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}.
The element is either a window or an empty workspace.

AeroSpace remembers the history of focused elements.
If the previously focused window has been closed,
`focus-back-and-forth` skips it and switches focus to the element that was focused before it.
If there is no element to switch focus to (e.g. right after AeroSpace startup),
the command exits with non-zero exit code.

Also see: <<workspace-back-and-forth, workspace-back-and-forth>>
// end::body[]
